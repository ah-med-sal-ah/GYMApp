\# 🏋️ GYMApp



\*\*GYMApp\*\* is a web-based gym management system designed to help gym administrators manage their clients and subscriptions digitally.



\## 📌 The Problem



Many gyms in Tunisia still rely on \*\*paper-based registration and client management\*\*.



This can make it difficult to:



\* Keep track of gym members

\* Manage client information

\* Know when a client's subscription is about to expire

\* Send reminders to clients

\* Organize membership information efficiently



\*\*GYMApp\*\* aims to provide a simple digital solution for these problems.



\## 💡 Our Solution



With GYMApp, a gym administrator can create an account and manage the gym's clients from one centralized system.



Instead of relying on paper, the administrator can manage client information digitally and receive automated reminders about upcoming subscription expirations.



\## ✨ Main Features



\### 👤 Gym Administrator



\* Create a gym administrator account

\* Manage gym clients

\* Add new clients

\* View client information

\* Update client information

\* Delete clients

\* Manage client subscriptions



\### 👥 Client Management



GYMApp provides a complete \*\*CRUD system\*\* for managing gym clients:



\* \*\*Create\*\* a client

\* \*\*Read\*\* client information

\* \*\*Update\*\* client information

\* \*\*Delete\*\* a client



\### 🤖 AI Agent \& Email Notifications



GYMApp includes an automated notification system.



When a client's subscription is approaching its expiration date, the system sends an email reminder \*\*3 days before the subscription ends\*\*.



The notification can be sent to:



\* The gym administrator

\* The concerned client



This helps both the administrator and the client avoid forgetting about subscription expiration.
